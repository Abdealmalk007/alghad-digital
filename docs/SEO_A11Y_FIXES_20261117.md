## Hosting limitations and remaining steps

**GitHub Pages does not allow arbitrary response security headers from repository files.**
The HTML meta-CSP is applied in browsers but cannot implement HTTP-only directives such as HSTS, `frame-ancestors`, `X-Content-Type-Options` or `Referrer-Policy`. To deploy those headers, configure a suitable CDN/reverse proxy or a host with response-header controls, validate with `curl -I`, and test downloads/fonts/sources under CSP in Report-Only first. See `docs/HTTP_SECURITY_HEADERS.md`.

Real Google Search Console query impressions, clicks, CTR, coverage and rankings require OAuth access to the verified site property. No such account data was accessed by these tests. Code and crawl improvements cannot guarantee any Google placement.

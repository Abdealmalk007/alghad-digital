# ProTech HR

منصة Windows لإدارة شؤون الموظفين والحضور والإجازات والرواتب والتقارير.

تطبيق إداري بواجهة عربية للموارد البشرية، يغطي بيانات الموظفين والرواتب والحضور والتقارير. المستودع العام يحتوي المصدر وإصدار Windows تجريبي.

## المزايا الرئيسية

- ملفات الموظفين والسجلات الإدارية
- متابعة الحضور والإجازات والمواعيد
- حسابات ورواتب وتقارير الموارد البشرية
- مخرجات Windows Installer وPortable
- مستودع مصدر عام مع توثيق البناء

## الإصدار والمنصات

- الإصدار المعلن: 23.0.1.
- المنصات المعلنة: Windows.
- حالة الإتاحة: Beta / Preview — إصدار تجريبي.
- الحد الأدنى لإصدار النظام والذاكرة: غير متحقق؛ راجع ملاحظات الإصدار.

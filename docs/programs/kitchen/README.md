# Kitchen CAD Pro

تصميم المطابخ من مخطط الغرفة والخزائن إلى معاينة 3D والتصنيع والتصدير — المشروع قيد التطوير والتجربة، وليس إصدارًا نهائيًا. للطلب أو الاستفسار، تواصل معنا عبر واتساب أو البريد الإلكتروني.

منصة تصميم وهندسة مطابخ متقدمة في مرحلة التطوير؛ تستهدف الربط بين التصميم ثنائي الأبعاد وثلاثي الأبعاد، الكتالوجات، الخزائن، الرخام، المواد، ومخرجات التصنيع هذا البرنامج في مرحلة التطوير والتجربة، وليس إصدارًا نهائيًا صالحًا للاعتماد الإنتاجي. للطلب أو الاستفسار عن توفره، تواصل معنا عبر واتساب أو البريد الإلكتروني.

## المزايا الرئيسية

- تخطيط الغرف والفتحات والأبواب والنوافذ
- كتالوجات للخزائن والأجهزة والمواد
- نمذجة 2D و3D وإضاءة ورندر
- رخام وملحقات وقوائم قص وتكلفة وتصنيع
- حفظ وتصدير المخرجات الفنية

## الإصدار والمنصات

- الإصدار المعلن: V5 Kitchen Design R3 Beta.
- المنصات المعلنة: Windows.
- حالة الإتاحة: Beta / Preview — إصدار تجريبي.
- الحد الأدنى لإصدار النظام والذاكرة: غير متحقق؛ راجع ملاحظات الإصدار.

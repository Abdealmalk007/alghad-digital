# Daily Work Reports

إنشاء تقارير عمل يومية مخصصة بالكامل دون أسماء أو أقسام مفروضة مسبقًا.

نسخة عامة مرنة للتقارير اليومية؛ يبدأ المستخدم من سجل فارغ وينشئ العناوين والأقسام والموظفين والحقول بحسب طبيعة عمله، مع مسارات تطوير Windows وAndroid.

## المزايا الرئيسية

- حقول وأقسام وعناوين قابلة للتخصيص من الصفر
- واجهة عربية تناسب التقارير التشغيلية اليومية
- مسار إعداد أولي لا يحتوي بيانات افتراضية خاصة
- إدارة سجلات التقارير وأعمال الفريق
- مصدر Windows وAndroid متاح على GitHub

## الإصدار والمنصات

- الإصدار المعلن: 15.5.0.
- المنصات المعلنة: Windows / Android.
- حالة الإتاحة: Beta / Preview — إصدار تجريبي.
- الحد الأدنى لإصدار النظام والذاكرة: غير متحقق؛ راجع ملاحظات الإصدار.

## التثبيت والتشغيل

اختر الملف الموافق لمنصتك من الروابط الرسمية. راجع تعليمات الإصدار، واحتفظ بنسخة من بياناتك قبل التحديث. قارن SHA-256 عند نشره؛ لا تعطّل حماية النظام لمعالجة تحذيرات التوقيع. لا توجد أوامر بناء أو تثبيت dependencies عامة تنطبق على جميع البرامج.

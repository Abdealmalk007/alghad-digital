# Daily Work Reports

إنشاء تقارير عمل يومية مخصصة بالكامل دون أسماء أو أقسام مفروضة مسبقًا — هذا إصدار تجريبي (Beta/Preview) غير معتمد نهائيًا. للطلب أو الاستفسار، تواصل معنا عبر واتساب أو البريد الإلكتروني.

نسخة عامة مرنة للتقارير اليومية؛ يبدأ المستخدم من سجل فارغ وينشئ العناوين والأقسام والموظفين والحقول بحسب طبيعة عمله، مع مسارات تطوير Windows وAndroid نسخة تجريبية Beta/Preview وليست إصدارًا نهائيًا معتمدًا؛ اختبر التطبيق واحتفظ بنسخة احتياطية قبل استخدامه. للطلب أو الاستفسار عن البرنامج، تواصل معنا عبر واتساب أو البريد الإلكتروني.

## المزايا الرئيسية

- حقول وأقسام وعناوين قابلة للتخصيص من الصفر
- واجهة عربية تناسب التقارير التشغيلية اليومية
- مسار إعداد أولي لا يحتوي بيانات افتراضية خاصة
- إدارة سجلات التقارير وأعمال الفريق
- مصدر Windows وAndroid متاح على GitHub

- الإصدار المعلن: 15.5.0.
- المنصات المعلنة: Windows / Android.

# Google Maps Reviews Tracker

برنامج Windows تجريبي لمراقبة تقييمات الفروع ومراجعات العملاء وتحليل السمعة والتقارير. تتطلب ميزات Google الرسمية إعداد API/OAuth مصرحًا به.

لوحة قيادة عربية وإنجليزية تعرض الفروع والتقييمات التاريخية ومراجعات العملاء ومتابعتها والتقارير Excel وCSV وPDF. إصدار Beta غير موقّع رقميًا. لا يمكن الحصول على جميع مراجعات المنافسين من Places API؛ المصدر يقدم عينة مراجعات محدودة. تتطلب مراجعات الفروع المملوكة صلاحية Google Business Profile OAuth. لم يُعتمد اختبار مزامنة حية شامل بعد.

## المزايا الرئيسية

- واجهة عربية RTL وإنجليزية ولوحة مؤشرات
- سجل تاريخي لتقييمات الفروع ومؤشرات تحليلية
- إدارة المراجعات ومتابعة الملاحظات والتنبيهات
- تصدير بيانات إلى Excel وCSV وPDF مع حماية النصوص
- Places API وBusiness Profile API مع صلاحيات Google الرسمية

## الإصدار والمنصات

- الإصدار المعلن: 42.0.0-beta.1.
- المنصات المعلنة: Windows.
- حالة الإتاحة: Beta / Preview — إصدار تجريبي.
- الحد الأدنى لإصدار النظام والذاكرة: غير متحقق؛ راجع ملاحظات الإصدار.

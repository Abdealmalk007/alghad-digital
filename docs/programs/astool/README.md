# أسطول | ASTOOL

إدارة السيارات والسائقين والوقود والصيانة والمصروفات والتقارير. نسخة تجريبية غير موقعة، للاختبار فقط.

لوحة تحكم تفاعلية، سجل السيارات والسائقين، تقارير PDF وExcel وCSV واستيراد بيانات السيارات. تنبيهات المستندات المسجلة. النسخ الاحتياطي الشامل وكروت التشغيل لم تكتمل بعد.

## المزايا الرئيسية

- لوحة تحكم وتحليلات
- إدارة السيارات والسائقين
- سجل الوقود والصيانة
- تقارير PDF وExcel وCSV
- تنبيهات صلاحية المستندات المسجلة

## الإصدار والمنصات

- الإصدار المعلن: 0.1.0-beta.5.
- المنصات المعلنة: Windows.
- حالة الإتاحة: Beta / Preview — إصدار تجريبي.
- الحد الأدنى لإصدار النظام والذاكرة: غير متحقق؛ راجع ملاحظات الإصدار.

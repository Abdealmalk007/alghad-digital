# ProTech Music

مشغل ProTech Music للأندرويد مع فهرسة الصوتيات المتاحة تلقائيًا، تصنيف واتساب والتنزيلات، قوائم مخصصة ومشاركة ومؤثرات صوتية. إصدار Beta تجريبي لم يجتز جميع اختبارات الأجهزة بعد.

إصدار 0.4.2 Beta للأندرويد 8 والأحدث. يفهرس الصوتيات المتاحة عبر MediaStore بعد موافقة المستخدم، ويجمعها حسب التطبيقات والمجلدات. تستطيع إنشاء قوائم وإضافة المقاطع أو إزالتها من القوائم دون حذف الأصل، أو مشاركة مقاطع متعددة، وتشغيل القوائم بالترتيب أو عشوائيًا وتغيير التكرار. يوجد Equalizer وBassBoost ومضخم محدود +6 dB عند دعم الجهاز. يتطلب الحذف النهائي تأكيد التطبيق وموافقة Android. اختُبر على محاكي Android 15 فقط؛ ليس إصدارًا نهائيًا ولا نضمن توافق جميع الهواتف بعد.

## المزايا الرئيسية

- فهرسة تلقائية لصوتيات الجهاز المسموح الوصول إليها
- تصنيف واتساب والتنزيلات والتسجيلات وتيليجرام
- قوائم تشغيل مخصصة وتحكم بالترتيب والخلط والتكرار
- تحديد ومشاركة عدة مقاطع وحذف نهائي بموافقة Android
- Equalizer وBass Boost ومضخم صوت محدود حسب دعم الجهاز
- غلاف المقطع وكلمات LRC متزامنة مع التشغيل
- تبديل العربية والإنجليزية وتحسين الشاشات الصغيرة والوضع الأفقي
- بحث أسرع وفهرسة مؤقتة للمكتبات الصوتية الكبيرة

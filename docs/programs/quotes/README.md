# ProTech Quotes & Contracts

برنامج Windows لإدارة عروض الأسعار والعقود والعملاء والمشاريع والمخزون والدفعات والتقارير.

إصدار Beta تجريبي يدعم قوالب عربية قابلة للتخصيص وعقودًا ومقاسات وتسعيرًا وتقارير PDF وDOCX وXLSX وCSV؛ لا يدعم الفواتير الضريبية المعتمدة من ZATCA حاليًا.

## المزايا الرئيسية

- قوالب عروض أسعار وعقود عربية قابلة للتعديل
- إدارة العقود والمشاريع والمقاسات والعملاء
- إدارة التسعير والمخزون والدفعات
- معاينة وطباعة وتصدير PDF وWord وExcel وCSV
- نسخ احتياطي موثق واستعادة موضع العمل

## الإصدار والمنصات

- الإصدار المعلن: 2.0.0-beta.2.
- المنصات المعلنة: Windows.
- حالة الإتاحة: Beta / Preview — إصدار تجريبي.
- الحد الأدنى لإصدار النظام والذاكرة: غير متحقق؛ راجع ملاحظات الإصدار.

# ProTech Quotes & Contracts

برنامج Windows لإدارة عروض الأسعار والعقود مع إصدار Beta.3 الجديد لإدارة العميل باسمه ورقم جواله وعنوانه، والقوالب والمشاريع والتقارير.

إصدار v2.0.0-beta.3 التجريبي (Customer RC3): يتضمن حقول اسم العميل الإلزامي، رقم الجوال مع تطبيع الرقم السعودي المحلي والدولي، والعنوان الأساسي الإلزامي. يدعم إضافة وتعديل العملاء والبحث والسجلات، ويحافظ على لقطات المستندات الصادرة دون تعديل تاريخها. في QA اجتاز 212/212 اختبار Python و14/14 اختبار EXE واختبارات التثبيت والترقية. نسخة غير موقّعة رقميًا (NotSigned) وقد يظهر تحذير SmartScreen، كما لم تُعتمد بعد مراجعة تراخيص Qt LGPL والاعتماديات بشكل مستقل. البرنامج تجريبي وغير معتمد كإصدار نهائي، ولا يقدم فواتير ضريبية معتمدة من ZATCA حاليًا. احتفظ بنسخة احتياطية قبل التجربة.

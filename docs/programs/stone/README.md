# ProTech Stone Manager

إدارة احترافية لأعمال الرخام والبورسلان: العملاء والعقود والألواح والمخزون والتقارير.

برنامج Windows مخصص لشركات الرخام والبورسلان؛ ينظم العقود والمواد والمستودع والمرفقات والفواتير والتقارير، مع فصل بيانات كل مستخدم.

## المزايا الرئيسية

- إدارة العملاء والعقود مع نوع المادة واللون والسماكة والمساحة
- كتالوجات الرخام والبورسلان والغراء والألواح والهانيكام
- إدارة الوارد والصرف والجرد وتقارير المخزون
- تصدير PDF وExcel وCSV وطباعة التقارير
- مرفقات الصور والملفات وإعدادات شعار الشركة

## الإصدار والمنصات

- الإصدار المعلن: 2.0.0.
- المنصات المعلنة: Windows.
- حالة الإتاحة: Beta / Preview — إصدار تجريبي.
- الحد الأدنى لإصدار النظام والذاكرة: غير متحقق؛ راجع ملاحظات الإصدار.

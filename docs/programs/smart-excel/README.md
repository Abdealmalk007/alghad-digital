# SmartExcelAnalyzer

برنامج Windows لتحليل ملفات Excel وتنظيم البيانات وعرض النتائج والتقارير.

منصة تحليل بيانات محلية للحاسب، تجمع أدوات معالجة جداول Excel والتحليل والإحصاءات وإخراج النتائج. النسخة 30.7.3 موحّدة مع تحديث إلغاء شاشة تسجيل الدخول، وهي نسخة تجريبية غير موقّعة رقميًا.

## المزايا الرئيسية

- استيراد الجداول والعمل على بيانات Excel
- تحليل وإحصاءات تساعد على استكشاف البيانات
- عرض المخططات ومخرجات التقارير
- تثبيت موحّد يشمل التحديثين 30.7.1 و30.7.3
- إلغاء شاشة تسجيل الدخول المحلية وفق تعليمات التحديث

## الإصدار والمنصات

- الإصدار المعلن: 30.7.3.
- المنصات المعلنة: Windows.
- حالة الإتاحة: Beta / Preview — إصدار تجريبي.
- الحد الأدنى لإصدار النظام والذاكرة: غير متحقق؛ راجع ملاحظات الإصدار.

اختر الملف الموافق لمنصتك من الروابط الرسمية. راجع تعليمات الإصدار، واحتفظ بنسخة من بياناتك قبل التحديث. قارن SHA-256 عند نشره؛ لا تعطّل حماية النظام لمعالجة تحذيرات التوقيع. لا توجد أوامر بناء أو تثبيت dependencies عامة تنطبق على جميع البرامج.

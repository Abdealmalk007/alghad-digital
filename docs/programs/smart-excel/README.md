# SmartExcelAnalyzer

برنامج Windows لتحليل ملفات Excel وتنظيم البيانات وعرض النتائج والتقارير — هذا إصدار تجريبي (Beta/Preview) غير معتمد نهائيًا. للطلب أو الاستفسار، تواصل معنا عبر واتساب أو البريد الإلكتروني.

منصة تحليل بيانات محلية للحاسب، تجمع أدوات معالجة جداول Excel والتحليل والإحصاءات وإخراج النتائج. الإصدار 30.7.9 يوفر واجهة عربية RTL حديثة، وبحثًا في أي عمود، وDashboard ديناميكيًا يعرض كل الموظفين والفروع والألوان عبر قائمة قابلة للبحث والتصفح والتصدير الكامل CSV؛ مع نسختي Setup وPortable. الإصدار Beta وغير موقّع رقميًا نسخة تجريبية Beta/Preview وليست إصدارًا نهائيًا معتمدًا؛ اختبر التطبيق واحتفظ بنسخة احتياطية قبل استخدامه. للطلب أو الاستفسار عن البرنامج، تواصل معنا عبر واتساب أو البريد الإلكتروني.

## المزايا الرئيسية

- استيراد الجداول والعمل على بيانات Excel
- تحليل وإحصاءات تساعد على استكشاف البيانات
- عرض المخططات ومخرجات التقارير
- بحث في أي عمود وDashboard تفاعلي حسب التجميع والمقياس
- عرض كل الموظفين والفروع والألوان دون حذف الفئات وتصدير CSV كامل

## التحليل الديناميكي الكامل

يمكن البحث في أي عمود أو جميع الأعمدة، ثم اختيار عمود مختلف للتجميع ومقياس عدد السجلات أو المجموع أو المتوسط. تعرض الرسوم Top 8 كملخص بصري فقط، وتتوفر جميع الفئات والأعداد والمقاييس في جدول مستقل قابل للبحث والتنقل (60 فئة في الصفحة) وتصدير CSV كامل. يدمج البرنامج الجداول المتوافقة فقط ويبقي الجداول الأخرى متاحة منفردة. الإصدار Beta غير موقّع Authenticode، ولم يُختبر تثبيت ملف Setup العام فوق النسخة السابقة؛ تحقق من SHA-256 واحتفظ بنسخة احتياطية.

## الإصدار والمنصات

- الإصدار المعلن: 30.7.9.
- المنصات المعلنة: Windows.
- حالة الإتاحة: Beta / Preview — إصدار تجريبي.
- النظام المدعوم للاختبارات: Windows 10/11 x64؛ متطلبات الذاكرة بحسب حجم الملف، ولم تُعتمد لكل البيئات.

# SmartExcelAnalyzer

إصدار 30.7.11: واجهة عربية RTL محسّنة ومساحة أوسع للرسوم. أُزيل اختصارا مركز المؤسسة ومنصة المؤسسة، وبقي في أسفل القائمة تسجيل الخروج والنسخ الاحتياطي. يمكن البحث في أي عمود وعرض جميع الموظفين والفروع والألوان عبر زر عرض الكل، مع قائمة قابلة للبحث والتصفح والتصدير الكامل CSV. تم التحقق من دقة التجميعات والحسابات باستخدام بيانات مرجعية ضمن الاختبارات، لكن ذلك لا يضمن معالجة كل ملفات Excel على الإطلاق. Beta غير موقّع رقميًا؛ احتفظ بنسخة احتياطية قبل التحديث.

برنامج Windows لتحليل ملفات Excel وتنظيم البيانات وعرض النتائج والتقارير — هذا إصدار تجريبي (Beta/Preview) غير معتمد نهائيًا. للطلب أو الاستفسار، تواصل معنا عبر واتساب أو البريد الإلكتروني.

منصة تحليل بيانات محلية للحاسب، تجمع أدوات معالجة جداول Excel والتحليل والإحصاءات وإخراج النتائج. الإصدار 30.7.11 يوفر واجهة عربية RTL حديثة، وبحثًا في أي عمود، وDashboard ديناميكيًا يعرض كل الموظفين والفروع والألوان عبر قائمة قابلة للبحث والتصفح والتصدير الكامل CSV؛ مع نسختي Setup وPortable. الإصدار Beta وغير موقّع رقميًا نسخة تجريبية Beta/Preview وليست إصدارًا نهائيًا معتمدًا؛ اختبر التطبيق واحتفظ بنسخة احتياطية قبل استخدامه. للطلب أو الاستفسار عن البرنامج، تواصل معنا عبر واتساب أو البريد الإلكتروني.

## المزايا الرئيسية

- استيراد الجداول والعمل على بيانات Excel
- تحليل وإحصاءات تساعد على استكشاف البيانات
- عرض المخططات ومخرجات التقارير
- بحث في أي عمود وDashboard تفاعلي حسب التجميع والمقياس
- عرض الكل لكل الموظفين والفروع والألوان مع فلاتر وبحث وتصدير CSV كامل

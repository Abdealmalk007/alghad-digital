# خطة تحديث واجهة الغد الرقمي — ProTech UI 4.0

التاريخ: 2026-11-16
المستودع: Abdealmalk007/alghad-digital

## القرار المعتمد
الصفحة الرئيسية تمثل جميع برامج ProTech. يبقى Kitchen CAD Pro بطاقة ضمن الكتالوج فقط، مع إزالة صوره وإبرازه المنفرد من مقدمة الموقع وقسم البرامج المميزة. البرامج أولًا والأخبار ثانويًا.

## التغييرات التقنية
- ملف CSS مستقل: assets/home-redesign-v4.css.
- تحديث الصفحة العربية: index.html.
- تحديث الصفحة الإنجليزية ومولدها: en/index.html وscripts/build_en.py.
- تعديل app.js حتى لا يستبدل قسم المجالات ببطاقات منتجات مميزة قديمة.
- اختبارات الانحدار: tests/home-redesign-v4-test.cjs مع Smoke/Browser/Bilingual.

## الضمانات
- لا حذف لبرنامج Kitchen CAD ولا تغيير لصفحة التفاصيل أو روابطه.
- لا تعديل لإصدارات البرامج أو أخبار الموقع أو قياس الزيارات.
- تجنب تعديل ملفات المشروع الرئيسة التي تحتوي على عمل جار غير منشور، باستخدام Git worktree مستقل.
- عند الحاجة إلى التراجع، تتم العودة عن Commit الواجهة فقط.

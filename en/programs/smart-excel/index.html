PROTECH / PRACTICAL GUIDE

Analyze a sales workbook without changing the original

  1. Create a working copy. Use a single header row with clear names such as Date, Branch and Amount; keep the source untouched.
  2. Normalize dates and numeric formats. Review blank rows and repeated subtotals; do not silently turn missing values into zeros.
  3. Group amounts by branch, then reconcile the resulting total against the original column. Spot-check records before sharing the report.

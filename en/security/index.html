SHA-256 checksums

When a SHA-256 value is published, compare it with the downloaded file. On Windows, run Get-FileHash -Algorithm SHA256 against the downloaded file.

Preview releases and warnings

Beta/Preview does not mean stable. A checksum establishes file integrity against the listed digest, not that a file has been code-signed or malware-certified.
